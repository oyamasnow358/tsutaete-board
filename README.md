# つたえて ボード（MieeL）

カードを えらぶと ことばに なって 声で 伝わる、AAC（拡大・代替コミュニケーション）の アプリ。iPad・iPhone（たて・よこ）で つかえます。

- 段階：**1まいで**（1〜6まいの 大きな カード → 「トイレに いきたいです」）／**2まいで**（なに・どこ → どうしたい）／**3まいで**（だれに → なに・どこ → どうしたい → 「やまだせんせい、トイレに いきたいです」）／**じゆうに**（なかまの タブ ＋ ⭐よく つかう）
- 助詞（に・を・が・と・で）と ていねいな いいかた（です・ください）を 自動で おぎなう（_src/compose.js）
- ことばの なかまごとの 色（ひと 黄・もの オレンジ・ばしょ むらさき・したい 緑・きもち 青・こたえ ピンク）
- 話した 文を 大きく 見せる（むきを かえる）、いそぎの 帯（トイレ・いたい・たすけて・やすみたい）
- 写真・先生の 録音・先生の なまえ カード、こどもごとの 設定
- えらびかた：タッチ／ながおし／連続タッチ よけ／1スイッチ スキャン（スペース・エンター）
- きろく：伝えた 回数・1回に つなげた まい数（へいきん）の 推移・よく つかう ことば・CSV、モデリングは 分けて 記録
- データは 端末の IndexedDB だけ（送信しない）。かきだし／よみこみ（写真・声 つき）

```
python _src/build.py        # _src/ → index.html, sw.js
python -m http.server 8826
```
